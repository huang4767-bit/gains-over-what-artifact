# Paper map

This file tells a reader where each table, figure, and key number of the paper and its supplement can be found in this repository. All paths are relative to the repository root. The supplement letters are: A re-check, B audit record, C coding, D margins and removal experiments, E electricity benchmark, F criteria.

Notation. `r` is the main control's error divided by the system's reported error; `r_a` is `r` on the datasets that pass the reproduction check. In `audit/margin_records.csv`, "full banded" means `record_class` = `full` and a non-empty `band` (337 rows).
